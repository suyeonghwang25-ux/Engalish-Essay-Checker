# Engalish - 영어 에세이 첨삭기

AI(Claude API)를 이용해 학생의 영어 에세이를 첨삭해주는, 영어 교사를 위한 웹 애플리케이션입니다. **손글씨 에세이 사진을 업로드하면 OCR로 텍스트를 판독**하고, 문법·어휘·문장구조·구성을 분석해 오류 위치를 색상으로 표시하며, 단어 수·세부 채점표·교사용 총평까지 한 번에 제공합니다. 물론 이미 타이핑된 텍스트를 붙여넣는 방식도 지원합니다.

## 주요 기능

- **손글씨 이미지 업로드 → OCR 판독 → 첨삭** (드래그 앤 드롭 지원, JPEG/PNG/GIF/WEBP, 장당 최대 5MB, **최대 5장까지 업로드 가능** — 여러 페이지짜리 손글씨 에세이도 순서대로 이어서 판독) 또는 텍스트 직접 입력
- 글씨가 불명확해 판독이 불확실한 부분은 "학생의 실수"와 구분하여 **OCR 판독 불확실 항목**으로 별도 표시
- 오류를 카테고리별로 **색상 하이라이트** (🔴 문법 / 🔵 철자 / 🟢 어휘 / 🟠 문장부호 / 🟣 문장구조 / 🟡 구성·논리 / ⚪ 기타) — 마우스 오버 시 수정 제안 확인
- **에세이 정보**: 단어 수, 문장 수, 평균 문장 길이
- **세부 채점표**: 문법(25) / 어휘(20) / 내용(20) / 구성(20) / 표기·문장부호(15) 항목별 점수·코멘트 + 총점(100점 만점)
- **교사용 최종 피드백**: 강점 / 보완할 점 / 다음 수업 지도 포인트 / 총평
- 필요한 부분만 수정한 **교정된 에세이** (변경된 부분은 굵게 표시)
- 학생 수준 선택 (초등 / 중등 / 고등 / 대학 / 일반 성인)

## 기술 스택

- Backend: Node.js, Express
- AI: Anthropic Claude API (`@anthropic-ai/sdk`, Claude Vision으로 손글씨 OCR + Zod 기반 structured outputs)
- Frontend: 순수 HTML / CSS / JavaScript (별도 빌드 과정 없음)

## 실행 방법

### 1. 의존성 설치

```bash
npm install
```

### 2. 환경 변수 설정

`.env.example` 파일을 복사하여 `.env` 파일을 만들고 Anthropic API 키를 입력하세요.

```bash
cp .env.example .env
```

```
ANTHROPIC_API_KEY=sk-ant-xxxxxxxx
PORT=3000
```

API 키는 [console.anthropic.com](https://console.anthropic.com/)에서 발급받을 수 있습니다.

### 3. 서버 실행

```bash
npm start
```

브라우저에서 `http://localhost:3000` 접속 후 사용하면 됩니다.

개발 중 파일 변경 시 자동 재시작하려면:

```bash
npm run dev
```

## 참고 사항

- 텍스트 입력은 최대 8,000자, 이미지는 장당 최대 5MB · 최대 5장(총 20MB 이하)까지 지원합니다.
- 손글씨 판독 품질은 사진 화질과 글씨체에 따라 달라질 수 있습니다. 판독이 불확실한 부분은 "OCR 판독 불확실" 항목으로 표시되니, 최종 확인 시 참고하세요.
- 응답은 참고용 AI 첨삭이며, 성적 처리나 공식 평가에는 교사의 최종 검토를 함께 받는 것을 권장합니다.
- API 사용에는 Anthropic API 요금이 부과됩니다 (이미지 입력은 텍스트보다 토큰 비용이 더 높습니다).
